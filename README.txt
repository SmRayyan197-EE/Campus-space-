CAMPUSSPACE - HTML/CSS/JAVASCRIPT VERSION

HOW TO RUN
1. Extract CampusSpace_HTML_Project.zip.
2. Open the extracted folder.
3. Double-click index.html, or right-click it and open with Chrome/Edge/Firefox.
4. No Python, Flask, database installation, or internet connection is required.

FEATURES
- Dashboard with 10 sample classrooms/labs
- Search and filter rooms by name, type, capacity, and equipment
- Booking form with date/time validation
- Prevents overlapping bookings for the same room
- My Bookings page and cancellation
- Weekly schedule (Monday-Sunday)
- Room administration: add/remove rooms
- Saves rooms and bookings in this browser using localStorage

IMPORTANT LIMITATIONS
This is a front-end-only HTML/CSS/JavaScript project. Data is saved only in the current browser on the current device. It is not a shared online database and has no login/authentication or multi-user server. For a real university-wide system, a backend and database are required.
